# AGENTS.md — правила работы Codex с проектом

## Главный режим

По умолчанию ничего не изменяй в файлах проекта.

Если пользователь просит посмотреть, разобраться, объяснить, составить план или предложить решение — только анализируй код и отвечай текстом.

Создавать, редактировать, удалять или форматировать файлы можно только после явного подтверждения пользователя, например:

- "Разрешаю внести изменения"
- "Можно писать код"
- "Применяй изменения"
- "Да, делай правки"

## Перед любыми правками

Перед изменением файлов сначала напиши план:

1. Что ты понял по задаче.
2. Какие файлы ты проверил.
3. Какие файлы нужно изменить.
4. Какие новые файлы нужно создать, если нужны.
5. Нужны ли изменения в базе данных.
6. Какие риски есть.
7. Как потом проверить результат.

После этого остановись и жди подтверждения пользователя.

## Архитектура проекта

Это самописный PHP MVC сайт для изучения английских слов.

Основные части проекта:

- `public/index.php` — вход для обычных страниц.
- `public/ajax.php` — вход для AJAX-запросов.
- `routes/web.php` — маршруты страниц.
- `routes/ajax.php` — AJAX-маршруты.
- `app/Controllers` — контроллеры.
- `app/Models` — модели БД.
- `app/Views` — шаблоны.
- `app/Core` — ядро проекта.
- `public/assets/js` — JavaScript.
- `public/assets/css` — CSS.

## Правила изменений

- Сохраняй текущую MVC-структуру.
- Не переносить проект на фреймворк.
- Не добавлять Composer-пакеты без отдельного разрешения.
- Не менять базу данных без отдельного плана.
- Не делать улучшения "заодно".
- Выполнять только поставленную задачу.
- Отвечать на русском языке.
